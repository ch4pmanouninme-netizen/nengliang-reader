# 跨平台 2.0 实施范围

本文件记录跨平台预览版的实现边界，供代码审查与后续维护使用。
本轮 v1.5.2 主页和聊天迁移要求见 [UPSTREAM-MIGRATION.md](UPSTREAM-MIGRATION.md)。

- 共享 C# 核心：TXT/EPUB 导入、阅读进度、分页、XML 备份恢复、去重。
- Avalonia 桌面界面：书架、设置、1～10 行阅读条、字体/透明度、查找、跳转、单书签、自动翻页。
- 平台隔离：Windows 热键与窗口样式；macOS Carbon 注册热键与 AppKit 鼠标穿透。
- 自定义全局快捷键，冲突反馈；托盘/菜单栏恢复操作。
- 使用同一种 TextLayout 测量与绘制，保持字符位置进度。
- 保留旧 XML 格式与书籍哈希；旧版旁边 data 目录采用可重试的复制迁移。
- 支持负坐标显示器；定期将不可见阅读窗口移回当前屏幕。
- TXT/EPUB 链接下载、取消、大小限制、超时、重定向上限、临时文件清理。
- 书库 ZIP 导入导出：跨设备迁移；重复书籍保留目的地现有进度。
- Windows x64、macOS arm64/x64 自包含构建；GitHub CI、草稿预发布工作流。

预览版不承诺：所有 macOS Spaces/全屏应用上方悬浮、云同步、网页抓取、自动更新、多书签、EPUB 图文排版。

旧 WinForms 源码保存在 legacy/，不参与新解决方案构建。平台类库不引用界面库，原生窗口句柄由桌面层传入。UI 线程处理阅读状态；导入/备份期间禁止并发编辑和保存，耗时文件处理在后台执行。

发布标准：核心测试、三架构构建与平台人工验收分别记录；编译成功不能替代 macOS 真机验证。未完成签名、公证及人工验收的 Mac 包只能作为开发预览分发。
