# 书库管理（2.0.2）

从主页进入“阅读”，在左侧对应的书籍上点击鼠标右键。菜单操作针对右键点到的书，不会误操作之前选中的另一行。

## 删除

选择“删除”，确认书名后再点击删除；取消或关闭确认框不修改书库。
删除会移除本机书库副本、该书阅读进度及书签，不删除书库以外的原始导入文件。
删除正在阅读的书会释放它的阅读条，切换到剩余书籍；删除最后一本后显示空书库。
不会影响聊天或主菜单。删除不能直接撤销，重要书籍可提前使用“书库备份 → 导出书库”。

写入书库索引失败会恢复该书及缓存。删除提交后若临时文件未清理，会显示提示，并在下次启动重试。
启动也会处理被中断的删除：索引尚未提交时恢复书籍，索引已提交时清理临时副本。

## 置顶

右键选择“置顶”，该书显示“置顶 · ”标记，并排到当前列表最前面。
再次右键选择“取消置顶”，恢复原导入顺序。多本置顶书之间保持原相对顺序。
全部书籍和各分组列表都优先显示置顶书。

## 分组

分组是一份**独立清单**，有自己的顺序；没有书的分组（空分组）也会保留，不会被自动清掉。

右键“分组”可以选择已有分组，或“新建分组…”输入名称把当前书放进去。一本书只属于一个分组，选择“未分组”可以移出当前组。
名称最多 40 个字符，不能包含换行，不使用保留名称“全部书籍”和“未分组”。相同名称忽略英文字母大小写，首尾空格会去掉。

**批量操作**：按住 Ctrl / Shift 多选书籍后再右键，菜单顶部会写明“以下操作作用于选中的 N 本书”，删除、置顶、分组都作用于整批。
多选只是为了好选，不会因此切走正在阅读的书 —— 只有恰好选中一本时，右侧正文才跟着切换。

**管理分组**：筛选下拉框右侧的“管理分组”按钮打开管理窗口，可以新建（含空分组）、重命名、删除，以及用“上移 / 下移”调整顺序。

- 重命名会同时改掉组内所有书的分组归属；改名撞上已存在的分组会被拒绝，不会把两个组混在一起。
- 删除分组只把组内的书移回未分组，**不会删书**。
- 上移 / 下移决定分组在筛选下拉框里的先后。

书库列表上方下拉框可以选择全部书籍、未分组或具体分组；已经按某个分组筛选时，列表行不再重复显示分组名。
新导入或下载的书仍为未分组，导入完成会切回全部书籍并选中它。

## 保存与备份

置顶和分组操作会立即保存，重启后保留。旧版书库默认未置顶、未分组，不改变已有阅读位置。
导出书库会包含置顶、分组、进度和书签；导入时新增书籍恢复这些信息，重复书籍保留当前设备已有信息。
此次只验证 Windows x64；跨平台界面代码已编译，macOS 实机交互尚未验证。
