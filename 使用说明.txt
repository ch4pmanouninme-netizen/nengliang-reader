良子小窗 · 1.5.2 局域网测试版

【启动与升级】
运行“良子小窗.exe”，先在主页选择“阅读”或“聊天”。两个功能可以同时使用，分别关闭。
客户端文件夹只需 EXE 和两份说明；聊天服务另放在服务文件夹。
升级前退出旧客户端，再使用这一版。本次只需退出并替换客户端；1.5.0 聊天服务继续使用。1.4 的旧聊天服务仍需升级。
Windows 10 / 11，需要 .NET Framework 4.8；不需要安装额外运行环境。

【导航】
阅读和聊天都保留“主页”按钮，统一从主页选择功能，不直接跳转到另一个子模块。
悬浮阅读右键菜单也可“返回主菜单”；返回主页只显示入口，保留当前阅读和聊天。
托盘右键“主页”或双击托盘图标可以找回入口。

【阅读】
选择“阅读”，打开 TXT / EPUB，点“显示”。可以拖入文件，或点“示例”。
阅读设置支持 1～10 行、字体、9～32 pt 字号、30%～100% 不透明度、置顶、2～60 秒自动翻页和鼠标穿透。
翻页按当前显示的一整页进行；隐藏或打开菜单会暂停自动阅读。
先拖动阅读条放好位置，再开启鼠标穿透。透明背景只留下文字，需在开启前调好位置和宽度。
双击正文或 F1 返回书架。右键正文可以设置、添加书签、查找和跳转进度。
书架“×”或阅读菜单“关闭阅读”只关闭阅读，保存进度并释放当前正文，不影响聊天。
TXT 支持 UTF-8 / UTF-16 / GBK / GB18030，最大 24 MB。
EPUB 提取纯文字，不加载脚本或外部网页；文件最大 100 MB，索引及正文展开合计最大 24 MB。
暂不支持 PDF、加密 EPUB、纯图片扫描书。

【聊天】
先由一台电脑运行聊天服务，启动后点“复制连接信息”，通过可信渠道发给同事。
主页选“聊天”，点“粘贴连接信息”，填写昵称，再点“连接”。
完整信息包含地址、端口、房间码和服务指纹。默认端口 38417。
本机自测地址可用 127.0.0.1；同事填写服务电脑的局域网地址。无需 Wi-Fi，网线也可以。
聊天使用 TLS 1.2 加密，并验证服务指纹；指纹错误时停止连接，不自动忽略校验。
服务程序关闭后重开会产生新指纹和房间码，需要重新复制；同一服务窗口内停止再启动可自动重连。
默认最多 30 人，昵称不能重复，每条消息最多 500 字符，每 10 秒最多发送 8 条文字消息。
Enter 发送，Shift+Enter 换行。消息区域可用滚轮、方向键、PageUp / PageDown / Home / End 查看历史。
“—”或 Esc 只是隐藏，连接仍在；从主页点“聊天”可以恢复；托盘菜单“主页”可恢复主菜单。
“×”会关闭聊天并断开、清空本机消息；“离开”也会断开并清空本机消息。
重新连接可能再次收到服务端保留的最近消息。本机清空不会删除别人或服务端的消息。
房间码、服务指纹和聊天记录不保存；地址、端口、昵称会保存。
目前只支持文字群聊，图片、附件、私聊、账号和撤回尚未实现。

【主题】
主页、阅读书架或托盘可选择“企业微信浅色 / IDEA 深色”，入口、阅读和聊天跟随切换。
同一个 Windows 用户运行的聊天服务会读取本机保存的主题，约半秒切换，不需要停止服务。
每个人的主题互相独立；不会因为一位同事选深色就修改全房间的配色。

【缓存与关闭】
服务端只保留最近 100 条文字消息，客户端显示最多 150 条消息或状态提示，超出会淘汰最旧内容。
接收待处理队列最多 182 条，连接发送队列最多 160 条，避免持续发消息无限增加内存。
界面处理过慢且接收队列满时，会断开再重连，只能获取服务端仍保留的最近消息。
关闭聊天或离开：清空本机消息和待处理队列，释放连接，不影响阅读和其他人。
停止或关闭服务：清空服务端历史，断开所有人；不会远程删除别人已显示的消息。
关闭阅读：保存进度并释放当前正文，已导入书籍仍在本机。
隐藏窗口不会清空缓存。内存引用释放后由 .NET 回收，占用不保证立刻下降。

【全局快捷键】
Ctrl + Alt + H：隐藏 / 恢复之前可见的入口、阅读和聊天窗口。
Ctrl + Alt + ← / →：阅读上一页 / 下一页。
Ctrl + Alt + 空格：自动阅读 / 暂停。
Ctrl + Alt + M：鼠标穿透开关；被占用时阅读模块会尝试 Ctrl + Alt + F10。
阅读条获得焦点且关闭穿透时，可用方向键 / PageUp / PageDown / 滚轮翻页、空格自动翻页。
Ctrl+B 添加书签，Ctrl+J 回书签，Ctrl+F 查找，Ctrl+G 跳转进度。
快捷键被其他软件占用时不会强行接管，可使用托盘。
关闭主入口只收进托盘；托盘右键“退出良子小窗”才会关闭全部客户端模块。
聊天服务是独立程序，退出客户端不会停止服务，需要在服务窗口单独停止。

【本机数据】
书籍、书签、进度、设置仍保存在 %LOCALAPPDATA%\NengliangReader。
新版沿用旧版数据，原阅读器与小窗不能同时打开同一数据目录。
程序文件夹不需要放小说、config、DLL、图片或 data 文件夹。

【网络安全】
加密保护传输，不代表实名验证或端到端加密，服务电脑仍能读取消息。
连接信息应通过可信渠道获取；拥有房间码的人可加入，不要转发给无关人员。
程序不自动修改公司防火墙或路由；仍用于局域网测试，不直接映射公网。
具体公司网段、终端隔离、防火墙和安全管理要求需要现场验证。
阅读完全离线，聊天不上传小说正文。服务操作见“服务说明.txt”。
