良子阅读器 · 1.3.1

【打开就用】
解压后，文件夹只需三个文件：
良子阅读器.exe
使用说明.txt
使用前必看！！！.txt

双击 EXE → 打开 TXT / EPUB（或点“示例”）→ 点“显示”进入悬浮阅读。
适用于已安装 .NET Framework 4.8 的 Windows 10 / 11。
不用安装，不用联网，也不需要额外的 config、DLL 或图片文件。

【主界面】
主界面缩为 620 × 360，标题为“文档”，不显示任务栏按钮。
没有品牌大字、宣传文案和绿色区域。右上角样式按钮切换企业微信浅色 / IDEA 深色，并同步调整阅读条。
拖动顶部空白处移动窗口；“—”或 Esc 隐藏；“×”退出。双击系统托盘的“文档”图标可恢复。
底部“打开 / 显示 / 设置 / 示例”分别用于打开文件、显示阅读条、调整设置和试用示例。

【在企业微信和 IDEA 里使用】
1. 先保持“鼠标穿透”关闭，拖动阅读条放到合适位置，左右边缘可调宽度。
2. 右键菜单或系统托盘选择“企业微信浅色样式”或“IDEA 深色样式”。
3. 默认只显示小字号正文，没有边框、圆点、阅读进度数字和悬停书名。
4. 放好位置后，开启“鼠标穿透”：点击文字也会操作下方窗口；翻页用全局快捷键。
5. 临时不看时按隐藏快捷键；再次按下恢复阅读条，不主动抢走打字焦点。

深浅色样式只是预设配色，软件主题不同可能有色差。想完全去掉背景，可在阅读设置里选择“透明 · 只留文字”。先调好位置和宽度，再开透明背景；透明部分无法接收拖动或调整宽度，只能点击文字区域。

【全局快捷键：在其他窗口中也可用】
Ctrl + Alt + H          隐藏 / 恢复
Ctrl + Alt + → / ←      下一页 / 上一页
Ctrl + Alt + 空格       自动阅读 / 暂停
Ctrl + Alt + M          开启 / 关闭鼠标穿透

隐藏键被占用时会依次尝试 Ctrl + Alt + F8、F9。
穿透键被占用时会尝试 Ctrl + Alt + F10。
实际隐藏和穿透按键显示在书架底部。全局翻页和自动阅读键若被其他软件占用，不会强行接管。
找不到窗口、无法右键或快捷键被占用时：双击右下角系统托盘中“文档”图标打开文档列表；托盘右键也能切换穿透、样式、设置和退出。

【鼠标穿透关闭，且阅读条获得焦点时】
→ / ↓ / PageDown / 滚轮向下：下一页
← / ↑ / PageUp / 滚轮向上：上一页
空格：自动阅读 / 暂停
Esc：隐藏
Ctrl + B：添加或更新书签
Ctrl + J：回到书签
Ctrl + F：查找文字
Ctrl + G：跳转阅读百分比
F1 / 双击正文：返回书架
右键正文：打开菜单

【阅读设置】
显示行数可选 1～10 行，默认一行。打开设置，调整“显示行数”后点“保存设置”即可。
正在阅读时，右键正文 → 阅读设置；开启鼠标穿透时，从系统托盘右键 → 阅读设置。
窗口高度随行数变化；下一页、上一页和自动阅读均按整页文字翻动。设置与阅读进度自动保存。
支持 9–32 pt 字号、30%–100% 不透明度、2–60 秒自动翻页间隔和置顶开关。
“极简阅读条”默认开启；取消可恢复边框、圆点和进度数字。
隐藏阅读条、打开菜单或设置时会暂停自动阅读。
不用时从托盘或阅读条菜单选择“退出”。

【书籍和进度存在哪里】
本机应用数据目录：%LOCALAPPDATA%\NengliangReader
可将这行路径粘贴到文件资源管理器地址栏打开。
此目录保存导入的正文、阅读位置、每本书一个书签和设置；原始书籍只读。
程序文件夹不会再生成 data、配置或日志文件。
阅读中每两秒保存变化；隐藏和退出时立即保存。强制结束可能丢失最后两秒的进度。

【从旧版升级】
如果旧版已经有阅读进度，请先退出旧版，将新版 EXE 放到旧版 data 文件夹旁运行一次。
首次运行时会将旧正文和进度复制到上述本机目录，保留旧数据。
本机目录已有进度时不会被旧进度覆盖。确认迁移成功后，可自行整理旧版文件。
换电脑时，除了三个程序文件，还需另外备份和复制 %LOCALAPPDATA%\NengliangReader 目录。

【支持的书籍】
TXT：UTF-8、UTF-16、常见 GBK / GB18030 中文编码，最大 24 MB。
EPUB：按章节顺序提取纯文本，不加载脚本和外部网页；文件最大 100 MB，索引和正文展开合计最大 24 MB。
暂不支持 PDF、加密 EPUB 和纯图片扫描书。
