# 良子小窗 · Windows

解压整个 ZIP 后，进入以版本号命名的文件夹（ZIP 名同样带版本号），双击其中的「良子小窗.exe」启动。电脑无需额外安装 .NET。

2.0.2 新增书库管理：主页进入阅读，在左侧对应书籍上点鼠标右键，可删除、置顶/取消置顶和分组；列表上方可以筛选分组。完整操作见 app/docs/BOOK-LIBRARY.md。

目录结构：

```text
良子小窗.exe
README.md
app/             主程序、运行环境、资源及完整文档
```

请保留 EXE 与 app 文件夹的相对位置，不要只复制 EXE。可以右键 EXE 创建桌面快捷方式。

从主页点击「聊天」→「创建房间」即可开启服务，也支持命令行 `良子小窗.exe --server`。

更新前请退出阅读器和独立聊天服务，备份书库，然后将新版解压到新文件夹。请勿直接覆盖旧版文件夹，以免遗留旧文件。

完整使用说明与许可证位于 app 文件夹。项目地址：https://github.com/ch4pmanouninme-netizen/nengliang-reader
