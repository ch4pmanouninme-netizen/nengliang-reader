# 良子小窗 · Windows

解压整个 ZIP 后，双击「良子小窗.exe」启动。电脑无需额外安装 .NET。

目录结构：

```text
良子小窗.exe
README.md
app/             主程序、运行环境、资源及完整文档
```

请保留 EXE 与 app 文件夹的相对位置，不要只复制 EXE。可以右键 EXE 创建桌面快捷方式。

从主页点击「启动独立聊天服务」即可开启服务，也支持命令行 `良子小窗.exe --server`。

更新前请退出阅读器和独立聊天服务，备份书库，然后将新版解压到新文件夹。请勿直接覆盖旧版文件夹，以免遗留旧文件。

完整使用说明与许可证位于 app 文件夹。项目地址：https://github.com/ch4pmanouninme-netizen/nengliang-reader
