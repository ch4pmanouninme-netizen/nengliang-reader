良子小窗 · 局域网聊天服务 1.5.0（随客户端 1.5.2 提供）

【启动与连接】
1. 在经常开机、接入公司网络的 Windows 电脑上运行“良子小窗-聊天服务.exe”。
2. 选择公司网线所在网卡的 IPv4 地址。程序优先列出有线网卡，但仍需确认，避免选虚拟网卡。
3. 保留默认端口 38417，确认房间码，点击“启动服务”。
4. 点“复制连接信息”，通过可信渠道发给同事。完整信息包括地址、端口、房间码、服务指纹。
5. 同事在新版客户端的主页选“聊天”，点“粘贴连接信息”，填写昵称，再点“连接”。
服务电脑本身也可运行客户端。网线即可，不要求 Wi-Fi；不同 IP 正常，关键是指定端口能互通。
本机自测可把地址改为 127.0.0.1；其他电脑必须填服务电脑的局域网地址。

【主题】
同一个 Windows 用户下，在良子小窗选企业微信浅色或 IDEA 深色，服务窗口约半秒跟随，无需重启。
服务读取本机保存的设置，不写入阅读数据，不改变其他电脑的主题。
服务在另一台电脑或另一个账户运行时，需要在那里选择主题。

【连接安全】
默认 TLS 1.2 加密，先验证服务证书 SHA-256 指纹，再传输房间码，不支持明文降级。
服务启动自动生成临时自签名证书，无需手动安装证书，不修改 Windows 信任库。
房间码不是实名账号，证书指纹必须来自可信渠道；服务器可以读取消息，不是端到端加密。
关闭服务程序再打开会生成新证书、新指纹和新房间码，需重新复制完整信息。
同一服务窗口内停止再启动会沿用证书和房间码，客户端可自动重连。
不要向无关人员转发连接信息；仍用于局域网测试，不直接映射公网。
本版不是公司身份、审计或安全审批系统的替代品。

【缓存与停止】
默认每房间最多 30 人，最近 100 条消息保留在内存，超过上限时自动删除最旧条目。
单条文字最多 500 字符，每连接每 10 秒最多发送 8 条文字消息。
发送队列有上限，慢连接积压时断开；握手并发和加入频率也有限制。
停止或关闭服务：清空历史、限流表和连接队列，所有客户端断开；不会删除别人已显示的消息。
聊天记录不写文件，内存释放由 .NET 回收，进程占用不保证立即下降。
服务电脑休眠、断网或关机后聊天中断，需要保持运行。
服务“—”只是最小化，仍运行；“×”在服务运行时会提示确认停止。
退出客户端不会退出独立服务端。

【连接不上时】
确认客户端是 1.5.2，聊天服务是 1.5.0，服务显示“运行中”，地址正确、房间码和服务指纹一致、昵称不重复。
先用本机客户端 127.0.0.1 验证，再用第二台电脑连接。
本机能连、同事不能连：检查服务电脑防火墙、不同网段访问规则和终端隔离。
如果 Windows 提示防火墙权限，按公司规定允许该程序在相应网络接收入站连接，不要关闭整个防火墙。
受公司策略管理的终端可能需要网络管理员处理；程序不会自动修改防火墙或路由。
可在另一台电脑的 PowerShell 运行下面命令，把示例地址换成实际服务地址：
Test-NetConnection -ComputerName 192.168.1.10 -Port 38417
True 表示端口可达，不代表指纹、房间码或协议正确；False 不能单独确定哪一层网络限制。
端口被占用时换端口，并让大家同步修改。电脑换 IP 后需通知大家新地址。

需要 Windows 10 / 11 和 .NET Framework 4.8。
